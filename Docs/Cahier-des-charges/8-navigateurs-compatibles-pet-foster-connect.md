# Navigateurs compatibles

Pet Foster Connect est prévu pour fonctionner sur les navigateurs web modernes :

- **Google Chrome**
- **Mozilla Firefox**
- **Microsoft Edge**
- **Safari**

L'application étant responsive, elle doit également pouvoir être utilisée depuis les navigateurs mobiles récents sur smartphone et tablette.

**Internet Explorer n'est pas pris en charge**, car il ne supporte plus correctement les technologies web modernes utilisées par le projet.

> Le projet ne contient pas de configuration `Browserslist` ni de cible navigateur spécifique dans Vite. Cette liste correspond donc aux navigateurs visés par le projet et non à une compatibilité certifiée par des tests sur chaque version.
